# Otthon Melege program: fűtéskorszerűsítés

Május 20-ától lehet fűtéskorszerűsítésre (konvektor cserére) pályázni az Otthon Melege program részeként, a teljes költség 60%-a, akár 750 ezer forint is elnyerhető.

Akit érint, [olvassa el a kiírást](http://konvektor2019.nfsi.hu).
